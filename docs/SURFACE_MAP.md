# Surface Map

`repo-automation-template` is a current reference implementation and maintainer toolkit. It is useful now, but it is not yet a broadly supported productized toolkit.

## Starter path

Use these first when getting oriented:

- `repo-automation/bin/codex-slice-preflight`
- `repo-automation/bin/repo-flow`
- `repo-automation/bin/pr-finish`
- `repo-automation/bin/repo-doctor`
- `repo-automation/bin/run-tests`

1. [README](../README.md)

## Current support boundary

Current public-alpha support is:

- public-alpha
- terminal-first
- useful now but not fully packaged
- not yet package-manager install
- not yet release bundles
- not yet subtree mode
- not yet automatic downstream commits/PRs
- not yet full non-GitHub provider support

See [Known Limitations](KNOWN_LIMITATIONS.md) for the support boundary details.
